# 05 · Flujo de trabajo en Figma

Fuente: "Figma UX Design Course for Beginners" (Aliena Cai, playlist ~2h).
La herramienta práctica para ejecutar todo lo demás.

## Flujo profesional (no saltar pasos)

**Wireframe → Mockup → Components → Prototype**

| Etapa | Conceptos | Aprendizaje accionable |
|---|---|---|
| **Wireframing** | Frames, formas simples, jerarquía sin color | Valida ideas rápido antes de codear. Enfócate en layout y flujo. Atajos: Rectangle (R), Text (T), Line (L). |
| **Mockups (hi-fi)** | Color, imágenes, tipografía, estilos | De low-fi a high-fi. Usa estilos de texto/color reutilizables. |
| **Auto Layout** | Espaciado automático, responsive, padding | **Imprescindible** para interfaces adaptables. "Duplicate with New Content" para listas. |
| **Components & Variants** | Botones, cards, iconos reutilizables | Mini design system: cambias una vez → se actualiza en todo. |
| **Prototyping** | Interacciones, transiciones, modals | Conecta pantallas para simular el flujo. Prueba antes de desarrollar. |
| **Design System & Alignment** | Estilos globales, grids, constraints | Sistemas escalables. Alineación precisa = look profesional. |
| **Figma AI** | Generar layouts, renombrar | Acelera, pero como asistente, no reemplazo del pensamiento UX. |

## Aprendizajes generales

- Consistencia desde el inicio: **Auto Layout + Components + Styles** ahorran tiempo enorme.
- Menos es más en wireframes; jerarquía cuidada en mockups.
- No solo dibujes bonito: piensa en flujos, fricciones y feedback.
- Crea proyectos reales para portafolio.

## Cómo encaja todo

- **Leyes de UX + Kole Jain** → el "por qué" y el taste.
- **Apple HIG** → consistencia nativa.
- **Refactoring UI** → espaciado y jerarquía.
- **Figma (Aliena)** → la herramienta para producirlo.

## Fórmula final
1. Entiende el problema del usuario.
2. Aplica Leyes de UX + HIG.
3. Ejecuta con los principios visuales (Kole + Refactoring UI).
4. Contrasta con patrones de apps top (Mobbin).
